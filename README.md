# 🛡️ Zero Trust Web Application en AWS

Proyecto desarrollado para la **Actividad 1 del Diplomado de Ciberseguridad**.

La solución implementa una aplicación web distribuida en AWS bajo un enfoque **Zero Trust**, utilizando separación entre Frontend y Backend, autenticación mediante JWT, comunicación privada entre VPC mediante VPC Peering, HTTPS, Fail2Ban y controles de seguridad.
